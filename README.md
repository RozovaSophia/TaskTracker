Простой и эффективный трекер задач для сотрудников. Данный проект разработан в качестве дипломной работы для демонстрации навыков создания RESTful API с использованием Django Rest Framework (DRF), контейнеризации с помощью Docker и соблюдения стандартов качества кода (PEP8, покрытие тестами >75%).



## О проекте
Проблема:
Во многих компаниях сотрудники и руководители сталкиваются с отсутствием прозрачности в задачах. Менеджеры не видят реальную загрузку команды, а сотрудники используют разрозненные инструменты (мессенджеры, почту) для учета задач. Это приводит к срыву дедлайнов и хаосу в коммуникации.

Решение:
Данный проект представляет собой API для трекера задач, который решает проблему учета поручений. Система позволяет:

Руководителям создавать задачи, назначать ответственных и отслеживать статус выполнения.

Сотрудникам видеть актуальный список задач, менять их статус и отчитываться о выполнении в едином окне.

## Бизнес-ценность
Внедрение данного решения позволяет количественно повлиять на эффективность работы отдела:

- Сокращение времени на ежедневные планерки по обсуждению статуса задач до 15 минут в день (экономия более 5 часов в месяц на одного руководителя).

- Исключение потери задач из-за "человеческого фактора" снижает риск штрафов за несвоевременное выполнение работы.

- Визуализация задач и прозрачность ответственности повышает личную эффективность сотрудников на 15-20% .

- Благодаря контейнеризации (Docker) система легко разворачивается на новых серверах при расширении штата.

## Функционал
- Разделение прав на Администратора (Manager) и Сотрудника (Employee).

- Полный набор CRUD-операций для задач.

- Жизненный цикл задачи (К выполнению / В работе / Выполнена).

- Возможность привязать задачу к конкретному сотруднику.

- Полностью функционирующий REST API.

- Интерактивная документация по адресу /swagger/.

- Запуск в одну команду благодаря Docker.
